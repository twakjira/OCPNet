Abstract

An interruption in a predicted mask biases estimates of crack length and width even when region overlap remains high. The orientation guided connectivity propagation network (OCPNet) therefore learns a supervised crack tangent field and uses it to steer deformable feature aggregation and connectivity propagation along the local crack direction. The orientation target comes from the structure tensor of the annotated mask, so no additional labelling is required.

Method

M1. Directional elongated context. Horizontal and vertical strip convolutions at several dilation rates enlarge the receptive field along the image axes.

M2. Supervised orientation head. A double angle vector and a crack confidence, learned from the structure tensor of the annotated mask.

M3. Orientation field deformable aggregation. Features sampled at signed offsets along the local tangent, returned as a residual scaled by the crack confidence.

M4. Directional connectivity propagation. Two recurrent steps exchange evidence with the tangent neighbours, gated by the crack confidence.

M5. Adaptive fusion. A pixelwise gate keeps the connectivity pathway from reducing pixel precision.
